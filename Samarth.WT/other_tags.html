1. br tag (line break)

Use : <br> is used to break the line and start text from next line. It has no closing tag.

2. hr tag (horizontal line)

Use : <hr> draws a horizontal line.
Attributes : width, size (thickness), color, align, noshade

3. pre tag (preformatted text)

Use : <pre> shows the text exactly as we type it. Spaces and new lines are kept. In normal html extra spaces are ignored.

4. p tag (paragraph)

Use : <p> is used to make a paragraph. Browser adds some space before and after it.
Attribute : align (left, center, right, justify)
