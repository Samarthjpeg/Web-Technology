Marquee Tag

Moving Text | Moving Image | Moving Hyperlink

Use : <marquee> tag is used to move text, image or link on the page.
Attributes : direction (left, right, up), scrollamount (speed), bgcolor, height

1. Moving Text

direction = left

direction = right,

direction = up (height = 80)
