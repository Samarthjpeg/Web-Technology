1. Font tag

Use : <font> tag is used to change style of the text.
Attributes : face (font name), size (1 to 7), color (colour of text)

2. Image tag

Use : <img> tag is used to show a picture on the page. It has no closing tag.
Attributes : src (path of image), alt (text if image not load), width, height, border, align
