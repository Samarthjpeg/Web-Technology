Formatting Styles and Headings

Jump to : Formatting Tags

1. Text Formatting Tags

Bold tag <b> - Use : it makes the text bold. No attribute is needed.
Example : This text is bold

Italic tag <i> - Use : it makes the text slanted (italic).
Example : This text is italic

Underline tag <u> - Use : it draws a line under the text.
Example : This text is underlined

Strike tag <strike> - Use : it draws a line through the text.
Example : This text is striked

Subscript tag <sub> - Use : it puts text little below the line.
Example : H2O is the formula of water

Superscript tag <sup> - Use : it puts text little above the line.
Example : (a+b)2 = a2 + 2ab + b2

2. Six types of Headings

Heading tags are <h1> to <h6>. h1 is biggest and h6 is smallest. Attribute used : align (left, center, right).
